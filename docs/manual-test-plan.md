# Mobile acceptance tests

1. Open the deployed website on Safari iPhone and desktop Chrome.
2. Verify navigation and buttons work and jar label updates with the entered brand.
3. Generate concepts repeatedly; confirm a concept changes the jar label.
4. Download the SVG sample and confirm it opens.
5. Save concept, refresh, restore and confirm values return.
6. Enter made-up application details only; submit sample.
7. Confirm the sample appears in the browser-only dashboard.
8. Export sample CSV; open it and confirm quoted fields render properly.
9. Clear samples and confirm the dashboard empties.
10. Verify no real email or customer data is transmitted.
11. Confirm mobile layout has no horizontal overflow.
12. Confirm browser developer console has no JavaScript errors.
