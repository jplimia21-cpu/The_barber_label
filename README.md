# The Barber Label

Private-label grooming brand website prototype.

## Current status
- `index.html`: self-contained static interactive preview with jar branding, browser-local sample applications, sample CSV export, and local concept saving.
- No real AI requests, payments, or customer submissions are active.
- The public repository contains no secrets.
- The live site has **not** been deployed yet.

## Preview locally
Open `index.html` in a browser, or host the repository as a static site.

## Deployment
Import this repository into a **separate** Vercel project, with Framework Preset **Other**, root directory `./`, no build command, and output directory `./`. Do not alter the Adulting project.

## Production requirements
Before collecting real applications: deploy server-side API, authenticated staff access, rate limiting, bot protection, consent/privacy policy, secure storage and retention controls, and test abuse cases. Never put service-role keys or OpenAI API keys in browser JavaScript.

## Product status
Prices and minimums are proposals, not binding offers. Final labeling, safety, compliance, fulfillment, and terms require review before launch.
